# Total Heat Pro

This repository contains the Total Heat Pro Laravel checkout app.

The application code lives in:

```text
offer/1
```

The production checkout URL is:

```text
https://swiss-crm-project.onrender.com/total-heat-pro/offer/1/checkout-now-v3
```

The `total-heat-pro` part is handled by Laravel routing, while the actual app folder remains `offer/1` so the same structure works locally and in Git.
